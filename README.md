# Customer Shopping Behavior Analysis

An end-to-end data analytics project using **Python, SQL, and Power BI** to explore customer shopping patterns and support data-driven retail decisions.

## Tools
- **Python:** pandas, Jupyter Notebook
- **PostgreSQL:** business-focused queries and customer segmentation
- **Power BI:** interactive dashboard

## Dataset
The dataset contains 3,900 records and 18 columns, covering customer demographics, purchases, discounts, ratings, subscriptions, and shopping preferences.

## Key Analysis
- Revenue by customer demographics
- Discount usage and product ratings
- Subscriber versus non-subscriber spending
- Customer segmentation by purchase history
- Product popularity and age-group revenue

## Project Files
- `customer_shopping_behavior.csv` — dataset
- `Customer_Shopping_Behavior_Analysis.ipynb` — Python analysis
- `customer_behavior_sql_queries.sql` — SQL queries
- `customer_behavior_dashboard.pbix` — Power BI dashboard
- Project report and presentation files

## Getting Started
1. Download or clone the repository
git clone <your-repository-url>
cd customer-trends-data-analysis-SQL-Python-PowerBI-main
Replace <your-repository-url> with the URL of your GitHub repository.
2. Explore the Python notebook
Install the main Python dependency if needed:
pip install pandas jupyter
Open Jupyter Notebook:
jupyter notebook
Open Customer_Shopping_Behavior_Analysis.ipynb. Make sure customer_shopping_behavior.csv is in the same directory as the notebook, or update the file path in the notebook.
3. Run the SQL analysis
   1. Import customer_shopping_behavior.csv into your SQL database.
   2. Use a table named customer or update the table name in customer_behavior_sql_queries.sql.
   3. Confirm that the column names and data types match the query references.
   4. Run the queries in your SQL client.
4. Open the Power BI dashboard
Install Power BI Desktop, then open customer_behavior_dashboard.pbix.
